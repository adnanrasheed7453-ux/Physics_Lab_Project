# Home Security Alarm System

## Physics Lab – First Semester Project

### Project Overview

The **Home Security Alarm System** is a simple security project designed to detect unauthorized movement inside a house.

The system uses a **PIR motion sensor** to detect movement. When motion is detected, the sensor sends a signal to the **Arduino Uno**, which activates a **buzzer** to produce an alarm sound.

This project demonstrates the practical use of sensors, electronic components, and microcontrollers in a basic home-security system.

## Objectives

* To design a simple home-security alarm system.
* To detect movement using a PIR motion sensor.
* To activate a buzzer when motion is detected.
* To understand the working of sensors and output devices.
* To apply Physics Lab concepts to a practical project.

## Components Used

* Arduino Uno
* PIR Motion Sensor
* Buzzer
* Jumper Wires
* USB/9V Power Supply

## Working Principle

1. The PIR sensor continuously monitors the surrounding area.
2. When movement is detected, the PIR sensor sends a signal to the Arduino.
3. The Arduino processes the signal.
4. If motion is detected, the Arduino turns ON the buzzer.
5. The buzzer produces an alarm sound.
6. After a short period, the buzzer turns OFF.

## Technologies Used
